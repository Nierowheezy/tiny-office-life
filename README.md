# Tiny Office Life

An interactive miniature isometric pixel-art virtual office with autonomous characters, daily routines, coffee breaks, and charming interactions.

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy to Vercel

This project is configured for zero-config deployment on Vercel.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/tiny-office-life)

Or connect your GitHub repo to Vercel and deploy automatically.
